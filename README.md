# CloudCone Email Manager

A tool for managing CloudCone email accounts - retrieve domains, list mailboxes, check storage usage, clean emails, and export results.

## Features / 功能特性

1. **Retrieve all domains** under your CloudCone account  
   获取cloudcone账号下所有的域名

2. **List all mailboxes** for a specific domain  
   获取某个域名下所有的邮箱

3. **Check mailbox storage usage**  
   获取邮箱占用的空间大小

4. **Clean mailbox emails** to free up space  
   清空邮箱邮件, 释放空间

5. **Auto-export deletion results** to CSV  
   删除结果自动导出csv
